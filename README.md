# Мой Tiguan — личный автожурнал

Локальное веб-приложение для учёта заправок, расходов и обслуживания дизельного Volkswagen Tiguan. Статические файлы для GitHub Pages; без сервера базы данных.

История хранится в IndexedDB на устройстве. Резервная копия JSON загружается пользователем отдельно. В репозитории нет истории расходов, координат, VIN, SQLite или резервных копий.

Google Drive требует отдельной настройки публичного OAuth Client ID в google-config.js; доступ ограничивается файлами приложения (drive.file). Токен только в памяти. До настройки интеграция выключена.

После установки откройте «Автомобиль» → «Восстановить» и загрузите свою резервную копию. Копии содержат личные данные: не загружайте их в этот репозиторий.
